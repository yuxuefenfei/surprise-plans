# 谜题与线索设计

每页采用不同的交互机制，保持新鲜感和参与度。

## 页面机制

### `index.html` — 案件接入页
- **机制**：终端启动动画 + 逐行显现日志
- **操作**：观看启动日志，点击"接入案件"进入
- **体验点**：赛博氛围建立，终端光标闪烁制造"实时感"

### `01-briefing.html` — 情报解锁扫描
- **机制**：加密卡片 + 解密动画
- **操作**：3张档案卡初始为加密态（`███ 数据加密`），每张卡需要点击"解密"按钮
- **流程**：点击解密 → 播放1.5秒解密动画（乱码闪烁）→ 内容显现 → 自动完成扫描
- **体验点**：从无脑点击 → 有"揭秘仪式感"，等待动画制造期待
- **后续迭代**：可加入 Q&A 验证（答对才给解密密钥）
- **配置字段**：`briefing.encryptedLabel`、`briefing.decryptBtnLabel`、`briefing.decryptingNotice`

### `02-evidence.html` — 关联配对游戏
- **机制**：线索-推论配对
- **操作**：6张卡片分为「线索卡」和「推论卡」各3张，随机混排。先点一张线索卡（高亮），再点一张推论卡尝试配对
- **反馈**：配对成功 → 卡片间显示关联说明文字；配对错误 → 卡片抖动 + 终端反馈
- **完成条件**：全部3对配对正确
- **体验点**：从单纯点击 → 需要思考"哪条线索对应哪个推论"，有轻度解谜感
- **配置字段**：`evidence.pairs` 定义配对关系和成功揭示文案

### `03-intercept.html` — 多段信号破译
- **机制**：3个独立信号节点 + 密码段累积
- **操作**：
  - 节点1「频率校准」：3个频率按钮（高/中/低），按正确顺序点击（中→低→高）
  - 节点2「信号锁定」：点击闪烁的信号点完成锁定（需锁定3次）
  - 节点3「波形匹配」：4个波形选项，选择匹配的那个
- **流程**：每个节点完成后 → 对应密码段自动填入 → 3段全部填入后解锁最终破译按钮
- **体验点**：从一次输入 → 3次小挑战的累积成就感，终端实时反馈每个节点状态
- **配置字段**：`intercept.segments` 定义每段的挑战类型和答案

### `04-reconstruction.html` — 拖拽时间线
- **机制**：HTML5 拖拽排序
- **操作**：上方「事件池」4张事件卡片随机排列，下方「时间线」4个空位。拖拽卡片到正确位置
- **反馈**：正确位置 → 绿色边框锁定；错误位置 → 卡片弹回 + 空位闪烁红色
- **移动端适配**：触摸设备改为"点击选中 → 点击放置"两步操作
- **完成条件**：4个事件全部放置正确
- **体验点**：从简单点击 → 有空间感的拖拽操作，错误有视觉代价
- **配置字段**：`reconstruction.scenes` 已有完整配置

### `05-verdict.html` — 隐藏彩蛋探索
- **机制**：打印报告后进入深度扫描模式
- **操作**：
  1. 点击"打印结论"观看逐行打印
  2. 打印完成后页面进入「深度扫描模式」
  3. 终端和面板中某些文字变为可点击的高亮词（虚线下划线提示）
  4. 点击高亮词 → 揭示隐藏信息
  5. 全部发现后显示最终信息
- **体验点**：从纯展示 → 有探索感的"发现隐藏信息"阶段，延长体验
- **配置字段**：`verdict.easterEggs` 定义触发词和揭示内容

## 案件进度

- 每个正式页面通过 `CONFIG.stage` 标记自身阶段。
- `assets/dossier-nav.js` 会自动注入顶部案件进度轨道。
- 进度使用 `localStorage` 记录已抵达的最远阶段；如果浏览器禁用存储，页面仍可正常浏览。

## 难度约束

- 每页应有明确提示。
- 错误操作要给反馈，不要让用户猜系统是否响应。
- 不设置倒计时。
- 不设置不可逆失败。
- 不依赖外部资源、网络或真实密码。

## 可替换谜题

- 短码可以换成目标昵称、纪念词或内部暗号。
- 证据卡可以换成真实生活细节。
- 事件重构可以换成"认识、熟悉、靠近、确认"的非日期版本。
- 彩蛋触发词和揭示内容可以完全自定义。

## 可达性注意

- 所有关键操作使用按钮或链接。
- 页面不依赖颜色作为唯一状态提示。
- `prefers-reduced-motion` 下关闭强动画。
- 拖拽操作在移动端有触摸替代方案。
