# 《赛博侦探机密档案》文案替换清单

这份清单用于后续快速替换人物信息、线索内容和最终揭示。

如果后续要把各页 `CONFIG` 抽成统一文件，先参考 `配置蓝图.md`。

- 真实称呼：

- 案件编号：
- 最终想揭示的内容：

## 二、页面对应字段

### `index.html`

- `caseId`：案件编号
- `targetAlias`：目标代号
- `intro`：接入页引导语

### `01-briefing.html`

- `targetAlias`：目标代号
- `clearanceLabel`：权限等级显示
- `briefing`：三张任务简报卡

### `02-evidence.html`

- `clues`：六条证据卡

建议把真实细节改写成证据，例如：

- “她总说的一句话”
- “你会优先回复的消息”
- “某个被你记住的小习惯”
- “你们之间只有彼此懂的暗号”

### `03-intercept.html`

- `passcode`：短码，默认 `TRACE`
- `hint`：提示文本
- `decoded`：破译后的隐藏消息

### `04-reconstruction.html`

- `correctOrder`：正确事件顺序
- `scenes`：事件卡内容

默认顺序：

1. 首次观察
2. 频繁注意
3. 保存细节
4. 承认异常

### `05-verdict.html`

- `targetAlias`：目标代号
- `verdictTitle`：结案标题
- `finalLines`：最终报告文本
- `restartLabel`：重看按钮文案

## 三、语气检查

- 有没有太像传统告白？
- 有没有用了星空、爱心、情书等旧项目意象？
- 每页有没有一个明确操作？
- 谜题是否 30 秒内可完成？
- 最终揭示是否和前面线索有关？
