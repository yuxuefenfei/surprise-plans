# 《赛博侦探机密档案》文案替换清单

> **快速替换指南**：90% 的文案只需修改 `assets/dossier-config.js` 即可完成替换。每个字段说明见 `配置蓝图.md`。

## 一、基础信息

修改 `DOSSIER_CONFIG` 顶层字段：

- `caseId`：案件编号，默认 `CD-0427`
- `targetAlias`：目标代号，默认 `[目标代号]`
- `investigatorAlias`：调查员称呼，**预留字段，暂未在页面中使用**
- `passcode`：短码，默认 `TRACE`（不区分大小写）

## 二、页面对应字段

### `index.html` — 案件接入页

对应 `pages.access`：

| 字段 | 说明 |
|---|---|
| `headline` | 主标题 |
| `intro` | 引导语 |
| `subIntro` | 副标题（"本调查不涉及危险品..."） |
| `bootLines` | 终端启动日志，每项支持 `text` 和 `className` |

### `01-briefing.html` — 任务简报页

对应 `pages.briefing`：

| 字段 | 说明 |
|---|---|
| `clearanceLabel` | 权限等级标签 |
| `instruction` | 页面说明文字 |
| `initialNotice` | 初始提示 |
| `progressNotice` | 进度提示，使用 `{done}` 占位符 |
| `completeNotice` | 完成提示 |
| `briefing` | 档案卡，每项为 `[标题, 内容]` |

### `02-evidence.html` — 证据墙页

对应 `pages.evidence`：

| 字段 | 说明 |
|---|---|
| `instruction` | 页面说明文字 |
| `initialNotice` | 初始进度，使用 `{total}` 占位符 |
| `progressNotice` | 进度，使用 `{done}` 和 `{total}` 占位符 |
| `completeNotice` | 完成提示 |
| `clues` | 证据卡，每项为 `[编号, 标题, 详情]` |

建议把真实细节改写成证据，例如：

- "她总说的一句话"
- "你会优先回复的消息"
- "某个被你记住的小习惯"
- "你们之间只有彼此懂的暗号"

### `03-intercept.html` — 信号截获页

对应 `pages.intercept`：

| 字段 | 说明 |
|---|---|
| `instruction` | 页面说明文字 |
| `hint` | 提示按钮内容 |
| `decoded` | 破译后的隐藏消息 |
| `packetLines` | 终端数据包内容 |
| `failNotice` | 破译失败提示 |
| `successNotice` | 破译成功提示 |

### `04-reconstruction.html` — 事件重构页

对应 `pages.reconstruction`：

| 字段 | 说明 |
|---|---|
| `instruction` | 页面说明文字 |
| `initialNotice` | 初始提示 |
| `progressNotice` | 进度提示，使用 `{next}` 占位符 |
| `completeNotice` | 完成提示 |
| `errorNotice` | 顺序错误提示 |
| `resetNotice` | 重置提示 |
| `correctOrder` | 正确事件顺序（数组） |
| `scenes` | 事件卡内容，每项为 `[编号, 标题, 详情]` |

默认顺序：

1. 首次观察
2. 频繁注意
3. 保存细节
4. 承认异常

### `05-verdict.html` — 结案报告页

对应 `pages.verdict`：

| 字段 | 说明 |
|---|---|
| `verdictTitle` | 结案标题 |
| `targetLabel` | 目标标签前缀（"档案对象："） |
| `finalLines` | 最终报告文本（数组） |
| `initialLines` | 终端初始文字 |
| `printLabel` | 打印按钮文案 |
| `printedLabel` | 打印后按钮文案 |
| `restartLabel` | 重看按钮文案 |

## 三、语气检查

- 有没有太像传统告白？
- 有没有用了星空、爱心、情书等旧项目意象？
- 每页有没有一个明确操作？
- 谜题是否 30 秒内可完成？
- 最终揭示是否和前面线索有关？

## 四、注意事项

- 进度存储在 `localStorage` 中，键名为 `cyberDossierStage`。如果接收方在共享/公用电脑上打开，下一个人会看到上一个人的进度。
- 短码不区分大小写（代码中用了 `.toUpperCase()`）。
- `localStorage` 被禁用时，进度不会保存，但页面仍可正常浏览。
