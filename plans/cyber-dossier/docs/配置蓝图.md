# 配置蓝图

当前正式页面已经使用 `assets/dossier-config.js` 作为统一内容配置。每个页面仍保留一个很薄的 `CONFIG`，只负责合并共享配置与当前页面阶段。

## 顶层信息

```js
const DOSSIER_CONFIG = {
    caseId: "CD-0427",
    targetAlias: "[目标代号]",
    investigatorAlias: "[调查员代号]",
    passcode: "TRACE"
};
```

## 抽取建议

当前已经落地：

- `assets/dossier-config.js`：存放顶层信息和所有页面文案
- `assets/dossier-nav.js`：注入案件进度轨道

仍保持纯静态，不引入构建工具。每页只负责：

1. 声明当前页面 key 和 stage
2. 引入共享 CSS、配置和进度轨道
3. 保留页面结构与交互逻辑

## 何时需要抽取

- 同一套站点要复制给多个人使用
- 线索和结案文字需要频繁替换
- 希望把真实信息集中到一个文件，减少漏改
- 后续计划增加多套文案风格
