# Plan Template

复制这个目录来创建新的网页编排计划。

推荐命名：

```text
plans/<kebab-case-plan-name>/
```

## 目录约定

- `prototypes/`：页面原型、动效实验、早期 `idea*.html`
- `site/`：已经编排完成、可直接打开或部署的正式网站
- `docs/`：策划、脚本、文案替换清单、维护说明
- `assets/`：图片、音频、视频、字体等素材

## 建议起步文件

```text
plans/<plan-name>/
├─ README.md
├─ assets/
├─ docs/
│  ├─ 页面剧情与文案策划.md
│  └─ 文案替换清单.md
├─ prototypes/
│  └─ idea1.html
└─ site/
   └─ index.html
```

## README 建议写清楚

- 计划主题
- 页面顺序
- 原型来源
- 成品入口
- 文档入口
- 后续待办
