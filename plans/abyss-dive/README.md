# Abyss Dive · 深海记忆潜航（升级版）

《深海记忆潜航》是一套将个人情感表达与深海科学考察深度结合的沉浸式网页编排计划。

不同于传统星空爱心或黑客终端，本作品将二人相识相伴的记忆与心意，伪装成一次向马里亚纳海沟 10,000 米深渊的深潜科考。随着深度增加、水压上升与光线消退，在深潜 AI「AQUA-09」的物理遥测与见证下，通过声呐脉冲、水压配平、水听器谐波与万米探照灯，一步步探寻深藏在静谧海底的最纯粹心意。

## 下潜阶段与深度路线

1. [00 浅海启航 (0m)](./site/index.html)：`index.html` — 切断外部喧嚣、潜艇注水自检、航行日志加载与下潜确认
2. [01 微光层探索 (200m)](./site/01-twilight.html)：`01-twilight.html` — 捕获漂浮发光水母，提取关于初见与生活习惯的 3 段记忆微光
3. [02 午夜区声呐 (1000m)](./site/02-sonar.html)：`02-sonar.html` — 启动主动声呐探测，根据声学脉冲完成心动三角定位
4. [03 深渊水压解谜 (4000m)](./site/03-pressure.html)：`03-pressure.html` — 应对 400 个大气压，手动调节双舷气压阀门稳定平衡
5. [04 海沟热泉共振 (6000m)](./site/04-resonance.html)：`04-resonance.html` — 调节水听器音阶与声波频率，激发海底热泉共鸣信标
6. [05 挑战者深渊 (10000m)](./site/05-challenger.html)：`05-challenger.html` — 开启万米超亮探照灯驱散黑暗，显影万米真言并探索 4 大隐藏真心话彩蛋

## 技术亮点

- **万米深潜全屏推进转场**：点击下潜时自动激活深度计高速跳字滚动、流速粒子拉伸与 Web Audio 引擎升频推进音效；到达新深度时自动释放减压气阀音与海洋钟声，彻底消除切页生硬感。
- **深海 AI 领航员「AQUA-09」实时通信**：每页顶部打字机输出客观物理遥测与情感常数分析。
- **纯算法 Web Audio 声效**：无需下载任何音频文件，纯代码实时合成声呐 Ping、水泡升腾、低频下潜嗡鸣、水听器空灵和弦与探照灯轰鸣。
- **全端自适应与可达性**：支持桌面鼠标与移动端触摸交互，内置 `prefers-reduced-motion` 动效降级保障。

## 定制指南

如果要为特定对象定制这套深潜体验：
1. 参阅 [docs/文案替换清单.md](./docs/文案替换清单.md) 准备双方昵称、记忆细节与真心话。

3. 双击打开 [site/index.html](./site/index.html) 即可开始下潜。
