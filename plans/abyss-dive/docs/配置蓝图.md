## 二、 核心机制与技术实现

1. **AI 电波自动注入与打字机**：`dive-nav.js` 会自动根据当前深度匹配 `aiAssistant.transmissions`，注入顶部通信框并平滑输出打字机动效。
2. **万米深潜全屏推进遮罩**：调用 `window.triggerDeepDescent(targetUrl, targetMeters, targetZoneName)` 触发数字飞速递增、流光拉伸、引擎升频音效，到达后自动触发减压气阀音与海洋钟声。
3. **纯算法 Web Audio 声效**：全由 Web Audio 纯算法实时生成，零外部音频网络请求。
