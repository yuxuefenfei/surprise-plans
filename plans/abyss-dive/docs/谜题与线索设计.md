## 二、 详细机制设计

### 1. 阶段 00：浅海启航（0m）
- **操作流**：
  1. 页面加载完成，显示当前水深 0m，环境为海面浅蓝色。
  2. 控制台提示“下潜系统就绪，请注水准备”。
  3. 用户点击“注水加压”按钮，触发注水音效（水流声），进度环从 0% 充注至 100%。
  4. 舱内自检完成，底部主按钮点亮为“下潜至 200m”。

### 2. 阶段 01：微光层探索（200m）
- **操作流**：
  1. 3 只半透明发光水母（CSS + SVG）在深蓝洋流中以正弦曲线缓速游动。
  2. 鼠标悬停/手指触碰水母时，水母发光强度增加。
  3. 点击水母，触发微弱气泡破裂音，水母化作一道记忆光斑并展开对应的深海日志卡片。
  4. 3 只全部收集后，顶部深度计解锁，提示“微光记忆归档完成，水压继续上升”。

### 3. 阶段 02：午夜区声呐（1000m）
- **操作流**：
  1. 界面呈现圆形声呐雷达显示屏，扫描线以 360° 匀速旋转。
  2. 用户点击“发射声呐脉冲”，播放纯正的 Web Audio `sonarPing()` 脉冲声，并在雷达上激起一圈扩散波纹。
  3. 随着扫描线扫过，雷达屏幕上浮现出 3 个闪烁的黄色回声光点。
  4. 用户点击光点完成声源解析，右侧控制台逐行显示声学特征（“心跳异常”、“偏爱信号”、“母港锚点”）。
  5. 3 处声源全部确认，完成 1000m 解密。

### 4. 阶段 03：深渊水压解谜（4000m）
- **操作流**：
  1. 仪表盘亮起红色“OVERPRESSURE WARNING”警报，背景伴有低频水压嗡鸣。
  2. 界面提供两根机械滑块控制杆：左舷排气阀（PORT VALVE）与右舷进水阀（STARBOARD VALVE）。
  3. 目标：将左右两个压力读数同时调整至绿色安全区（Target: 420 Bar）。
  4. 当两端指针均在绿色区间时，启动 1.5 秒倒计时锁定；倒计时结束即完成安全配平，警报消除，转为柔和蓝绿灯光。

### 5. 阶段 04：海沟热泉共振（6000m）
- **操作流**：
  1. 界面中心为示波器波形画布，显示一条微弱紊乱的海底水听器声波。
  2. 下方有 3 个频率谐波按钮（【低频 432Hz】、【中频 528Hz】、【高频 741Hz】）。
  3. 按照“陪伴的基调 $\rightarrow$ 偏爱的频率 $\rightarrow$ 坚定的承诺”（从低到高）依次点击激活。
  4. 每点击一次，示波器波形更趋近一条完美的共鸣正弦波，并播放一段清澈的空灵和弦音。
  5. 三阶频率对齐后，热泉喷口光芒大盛，信标点亮。

### 6. 阶段 05：挑战者深渊终极回响（10000m）
- **操作流**：
  1. 整个页面处于幽邃宁静的万米极深黑，水深指示 `10,928m`。
  2. 用户点击“开启主探照灯”，强光从中心锥形洒下，照亮海底信标。
  3. 终端打字机逐字输出 3 段深海结案词。
  4. 报告打印完成后，激活“深度扫描模式”，正文中的关键词（如“深渊”、“偏爱”、“万米”）带有微弱发光下划线。
  5. 用户点击关键词即可弹出隐藏在深渊底部的真心话彩蛋。

## 三、 难度约束与容错体系

1. **绝对无死局**：没有倒计时失败惩罚，操作错误随时可以重新调整（如滑块可无限次滑动）。
2. **移动端友好**：水母游动范围限制在可视区内，雷达光点热区放大，滑块支持 Touch 事件滑动。
3. **动效降级**：在开启 `prefers-reduced-motion` 时，关闭剧烈晃动与水母大幅度飘动，改为静态优雅布局。
